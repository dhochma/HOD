# פוסט לסושיאל

## לפני הכתיבה
1. לקרוא את `docs/brand.md` (טון) ואת `docs/business.md`.
2. להבין: **נושא**, **רשת** (לינקדאין / פייסבוק / שתיהן), **מטרה** (גיוס מועמדים, משיכת לקוחות, מיתוג מקצועי).

## התאמה לכל רשת
| | לינקדאין | פייסבוק |
|---|---|---|
| טון | מקצועי, תובנות מהשטח | חם, קליל, קהילתי |
| אורך | 600–1200 תווים | 300–600 תווים |
| פתיחה | משפט שעוצר גלילה: שאלה או תובנה | שאלה או משפט אישי |
| סיום | קריאה לפעולה ו-3 האשטגים | קריאה לפעולה, 1–2 אימוג'י |

## רעיונות לתוכן (כשדודי מבקש רעיונות)
טיפים לראיון עבודה, טעויות נפוצות בקורות חיים, מגמות בשוק ההנדסה והתעשייה, סיפור השמה (באנונימיות מלאה), משרות חמות, טיפים למעסיקים על גיוס.

## Airtable ו-Make
- דודי מפרסם דרך **Airtable** (טבלת תוכן) ו-**Make** (אוטומציה).
- אם דודי מבקש להכניס את הפוסט לתור: קודם לבדוק את מבנה הטבלה ב-Airtable (`list_bases` ← `list_tables_for_base`), להציג לדודי מה ייכתב, ו**רק אחרי אישור** ליצור רשומה.
- לא להפעיל או לשנות תרחישים ב-Make בלי אישור מפורש.
- כשמבנה הטבלה יתברר, לתעד אותו כאן (שמות טבלה ושדות) כדי לחסוך בדיקה בפעם הבאה.
