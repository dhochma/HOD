# מודעת דרושים

1. לקרוא את `docs/brand.md` (טון) ואת `docs/business.md` (פרטי קשר).
2. לבקש מדודי את מה שחסר. **חובה:** שם התפקיד, אזור, דרישות עיקריות. **רצוי:** תחום החברה (בלי שם החברה, כי דיסקרטיות), היקף משרה, שכר או טווח.
